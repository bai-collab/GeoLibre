# 嘉義市北社尾歷史地圖 GeoLibre 審視版

這是第一版審視專案，目標是讓教師先確認「圖層是否能開、北社尾是否在共同範圍、年代差異是否看得出來」。

## 如果畫面顯示「沒有數據圖層」

這代表目前開的是空白工作區，不是圖層遺失。請在 GeoLibre Web 或 Desktop 點上方「項目／项目」→「開啟／打開專案」，選擇本資料夾內的 `north-shewei-review.geolibre.json`。

在 GeoLibre Web 的實際選單路徑是「項目／项目」→「開啟來源／打开来源」→「文件／文件...」。直接進入 `web.geolibre.app` 不會自動載入這個 workspace 專案。

開啟成功後，左側「圖層」面板會列出五個圖層。每個圖層左側的眼睛／核取方塊就是開關：

- 1921 與 1983 是第一版主比較，會直接放在左側圖層清單上方，預設供 Layer Swipe 使用。
- 「候選圖層（教師用）」預設收合，裡面放北社尾專用圖、1945 舊航照、1935 歷史圖；教師需要時只要展開一次，學生平時不必逐一點開。
- 點圖層名稱旁的眼睛或核取方塊即可顯示／隱藏；下方「不透明度」滑桿可調整透明度。
- GeoLibre 的圖層面板預設保持在畫面左側；若被關閉，可點左側工具列的「圖層」按鈕重新顯示。

## 語言與預設位置

本專案的專案名稱、圖層名稱與教學說明已使用繁體中文。公開 GeoLibre Web 目前提供的是簡體中文 `zh` 目錄，專案 JSON 無法單獨把整個 GeoLibre 介面改成繁體；完整繁體介面要使用已加入 `zh-TW` 的本機 source 重新建置。

本次已在本機 GeoLibre clone 新增 `zh-TW` 語言目錄，並將新使用者的預設介面改為繁體中文；source 已推送至 [bai-collab/GeoLibre](https://github.com/bai-collab/GeoLibre/commit/9212cff) 的 `main`（commit `9212cff`）。公開的 `web.geolibre.app` 是否更新，仍取決於該 repo 的部署流程；若要讓學生直接使用完整繁體介面，需使用已更新的 source 建置後提供本機／校內版本。

本專案已把預設視野設在嘉義市北社尾：中心約為 `120.4255, 23.4994`、縮放等級 14。只要開啟本專案檔，初始畫面就會回到北社尾；若看到其他位置，通常是仍停留在空白工作區或開到別的專案。

## 第一版比較

- 1921：日治二萬五千分之一地形圖
- 1983：嘉義市圖
- 現代參考：OpenFreeMap Positron 向量底圖
- 比較工具：Layer Swipe、圖層開關、透明度

專案內另保存三個預設隱藏的候選層：北社尾專用圖（年代待查）、1945 舊航照、1935 歷史圖。它們已完成服務端點與單張圖磚探測，但尚未列入第一版主比較；狀態以 `data-manifest.json` 為準。

歷史圖層引用中央研究院[嘉義百年歷史地圖服務](https://gis.sinica.edu.tw/chiayi/)。專案只保存遠端圖磚網址，不鏡像大量影像。

## 審視方式

1. 在 GeoLibre Web 開啟 `north-shewei-review.geolibre.json`。
2. 確認畫面初始位置位於嘉義市北社尾附近。
3. 查看左側圖層清單，確認 1921 與 1983 圖層名稱清楚。
4. 打開 Layer Swipe，將滑桿左右移動，觀察道路、聚落與地形背景。
5. 分別將其中一層透明度調低，檢查兩張地圖是否能在同一範圍比較。

版面配置與窄版風險記錄在 `outputs/north-shewei-geolibre-map/layout-plan.json`；它把左側面板、地圖區與 Layer Swipe 的位置分開記錄。

## 學生可觀察的問題

- 哪些道路或地形線索在兩個年代都存在？
- 哪些聚落、道路或土地利用看起來增加、減少或改變？
- 這個變化是地圖上直接看見的證據，還是你的推測？
- 地圖比例尺、圖種與對齊誤差會不會影響判斷？

## 目前限制

- 1921 與 1983 圖層可作第一版比較，但仍是不同圖種與比例尺，不能把每個位置差異都當成精確測量結果。
- 「嘉義市（街）北社尾圖」已確認可取得圖磚，但其年代仍應回到原典補證，暫不當成確定年代層。
- 1945 舊航照與 1935 圖層先列候選，需再檢查是否完整覆蓋北社尾共同觀察範圍。
- 遠端服務能否使用，仍須在學校網路另做一次測試。
